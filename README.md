# 豆芽成长助手

小学生托管班管理系统，包含三个端：

- `weapp`：家长端与教师端微信小程序
- `admin-web`：机构管理端 Web 后台
- `server`：Go 后端、数据库迁移和 OpenAPI 接口说明

## 当前版本

当前代码为第三版开发成果，已覆盖家长入班申请、教师审核建档、班级权限、今日接送、拍照记录、作业、餐食、请假、每日总结、站内通知、通知投递记录、审计和隐私同意等功能。

刷脸、AI、积分和收费功能暂不属于当前版本。

## 文档

根目录中的 Word 文档包含第一版、第二版和第三版产品方案及技术方案。

## 本地运行提示

1. 分别进入 `weapp`、`admin-web` 和 `server` 安装依赖。
2. 将各项目的 `.env.example` 复制为本地环境文件，并按实际环境配置。
3. 正式微信小程序必须使用 HTTPS 后端地址，并配置微信合法域名。
4. 不要把本地 `.env`、微信开发者工具私有配置、对象存储密钥提交到仓库。
