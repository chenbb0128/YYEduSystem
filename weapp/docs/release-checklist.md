# 发布检查清单

- [ ] 已执行初始化脚本，`project.config.json` 使用真实 AppID、项目名和目标基础库版本。
- [ ] `.env.local` 的应用名称、API 地址、超时和存储前缀属于当前项目，且不包含任何秘密。
- [ ] `project.private.config.json` 中的 `urlCheck` 已按环境设置；生产验证不得绕过合法域名检查。
- [ ] request、uploadFile、downloadFile、WebSocket 等实际使用的域名均已加入微信公众平台合法域名。
- [ ] 后端业务响应结构和错误码已在领域 API 层统一处理。
- [ ] 登录失效 hook 已跳转到当前项目登录页，并正确清理或刷新本地凭据。
- [ ] 正式监控已通过 `configureErrorReporter` 接入，且 Token、手机号等敏感信息已脱敏。
- [ ] `src/app.json`、tabBar、分包和 `src/sitemap.json` 已覆盖全部正式页面。
- [ ] 主包、分包边界合理，主包没有反向依赖分包业务代码，包体积符合平台限制。
- [ ] 涉及用户信息、手机号、位置或其他个人信息时，已完成隐私协议、授权和隐私接口声明。
- [ ] 已执行 `pnpm check`，没有跳过类型、代码、样式或任一目标端构建。
- [ ] 已通过微信开发者工具、真机或体验版完成核心流程验证；关键页面已按需执行截图对比。
- [ ] 已确认 `dist/`、`.weapp-vite/`、环境变量、本地私有配置和临时截图没有被误提交。
