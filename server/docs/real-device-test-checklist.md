# 三端真机/联调测试清单

这是一份执行清单，不代表已经完成测试。每一项应由测试人员记录日期、设备、账号、结果和截图/日志。

## 管理员账号

- [ ] HTTPS 管理端打开，管理员登录、刷新页面、退出登录均正常。
- [ ] 创建/停用教师账号，教师账号无法进入管理员数据维护入口。
- [ ] 配置教师负责班级；同一教师多个班级可正常保存和查看。
- [ ] 新增、编辑、停用周期接送排班；重复有效日期规则被拦截。
- [ ] 点击“生成当天任务”，已有任务不会重复生成；生成结果能说明跳过原因。
- [ ] 查看家长入班申请、审核同名学生、驳回并填写原因。
- [ ] 查看餐食、作业、每日总结和通知投递日志。
- [ ] 查看审计记录，确认不出现 AppSecret、密码、Access Token 或完整手机号。

## 教师账号

- [ ] 教师账号密码登录；停用教师不能登录。
- [ ] 只能看到自己负责的班级，直接改 URL/请求参数不能访问其他班级。
- [ ] 查看当天排班生成的待确认任务，核对名单并确认教师/预计出发时间。
- [ ] 确认后家长站内通知出现；教师出发后每个孩子接到照片上传成功。
- [ ] 到班、未到班、异常、家长接走、请假和中途离班状态按业务规则可用。
- [ ] 临时学生可补充档案；收班检查会提示待照片/异常/档案问题。
- [ ] 按学校班级批量录入作业，逐学生反馈，发布每日总结。
- [ ] 录入明日餐食、复制历史菜单、上传实际照片、查看过敏备注。

## 家长账号（微信开发者工具 + 真机）

- [ ] 真机 `wx.login` 成功，服务端 code2Session 换取 OpenID；客户端伪造 OpenID 无效。
- [ ] 首次进入展示隐私说明；拒绝/加载失败时不能查看孩子动态，重试和返回登录可用。
- [ ] 家长提交孩子信息无需学生档案编号；不同班级写法能匹配或进入教师确认。
- [ ] 审核通过后自动出现绑定孩子，只能看到自己的孩子。
- [ ] 查看今日接送、校门口照片、到班状态、作业、餐食和每日总结。
- [ ] 提交请假、临时家长接走/自行到班变更，查看审核状态并可撤回待审核申请。
- [ ] 点击通知授权，分别验证同意、拒绝、关闭弹窗；站内通知始终可用。
- [ ] 验证接送、餐食、作业、请假、总结的微信订阅消息，并核对页面跳转。

## 故障和数据验证

- [ ] 停止 worker：业务写入成功，通知保留 pending；恢复 worker 后能发送/重试。
- [ ] 让微信发送返回错误：业务不回滚，投递日志为 failed，达到上限后不无限重试。
- [ ] MySQL 重启后学生、排班、接送、照片元数据和通知仍存在。
- [ ] S3 私有桶直链访问失败，签名 URL 过期或篡改后失败。
- [ ] 完成一次备份校验和隔离库恢复演练。
