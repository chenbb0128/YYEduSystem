# 豆芽成长助手隐私说明（上线前定稿稿）

## 我们处理什么信息

为了完成托管照护，系统会处理家长微信身份标识、家长联系方式、孩子姓名、学校班级、接送状态、现场照片、作业反馈、餐食及过敏/特殊饮食备注、请假信息和教师操作记录。

## 用途和范围

信息仅用于入班审核、接送安全核对、作业与餐食沟通、家长通知、异常追踪和安全审计。家长只能查看自己绑定孩子的数据，教师只能查看自己负责班级的数据，管理员按岗位权限维护机构数据。

## 照片和通知

接送及餐食照片保存在私有存储中，仅通过短时签名地址访问。订阅消息需由家长在小程序中主动授权；未授权或微信投递失败时，系统仍保留小程序内通知，不影响托管业务。

## 保存期限

默认照片保留 90 天，机构可以在生产配置中调整并应在服务协议中明示；业务档案、审计和请假记录按照机构法定/业务留存要求保存。超过期限的数据应由受控任务清理并保留审计记录。

## 家长权利

家长可以查看绑定关系、申请更正饮食备注、撤回待审核请假申请，并可通过机构客服申请查询、更正、导出或删除相关个人信息。涉及儿童信息的删除、解绑和导出必须先完成身份核验并由机构授权人员处理，不能仅凭一个前端 ID 操作。

## 联系方式和版本

上线前由机构填写运营主体、联系人、联系电话、投诉渠道和实际保存期限，并在小程序中展示当前协议版本。当前代码使用版本号 `privacy-v3-20260901`；正式发布前如文本发生变化，应升级版本并重新取得家长同意。
